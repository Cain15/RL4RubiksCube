
# RL4RubiksCube

A project exploring the use of **Reinforcement Learning (RL)** to solve a Rubik's Cube.

This repository contains my own implementation of **DeepCubeA**. The goal is to train a neural network to estimate the number of moves required to solve a given cube configuration and use this estimate to guide a search algorithm.

## Approach

### Reinforcement Learning

The project uses a neural network trained to estimate the cost of solving a Rubik's Cube from a given state.

Training combines two sources of experience:

- **Demonstrations:** Training examples generated by scrambling a solved cube and reversing the scramble. These provide known solution paths and upper bounds on the number of moves required.
- **Self-play:** The current network interacts with randomly scrambled cubes by selecting actions using an epsilon-greedy policy. The resulting transitions are stored in a replay buffer and used for further training.

The network predicts a q-value for each of the 12 possible cube rotations. These values represent the estimated number of moves required to solve the cube when taking a particular action first.

The network is trained using a Bellman-style cost-to-go update, combining the immediate cost of one move with the estimated remaining cost of the resulting state.

### Search

Once trained, the neural network is used as a heuristic to guide **Beam Search**.

Starting from a scrambled cube, Beam Search:
1. Generates possible successor states by applying valid moves.
2. Evaluates the successors using the trained neural network.
3. Ranks the candidates based on their estimated distance to the solved state.
4. Keeps only the best candidates up to a predefined beam width.
5. Repeats this process until a solved state is found or the maximum search depth is reached.

This combines the learned knowledge of the neural network with an explicit search algorithm to find a solution.

## Project Goal

The goal of this project is to explore how reinforcement learning and neural networks can learn useful representations of a Rubik's Cube state and how these learned estimates can guide search algorithms towards solving the puzzle.
